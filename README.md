# ExpANN

An experimental project to implement FusionANNS (Tian B, Liu H, Tang Y, et al. Fusionanns: An efficient cpu/gpu cooperative processing architecture for billion-scale approximate nearest neighbor search[J]. arXiv preprint arXiv:2409.16576, 2024.), current SOTA of on-disk ANNS system. My purposes are to understand ANNS algorithms better, to practise my engineering skills, and to amuse myself in this tedious life.

NO GUARANTEE is given on correctness/efficiency/consistency, as I am a beginner. But feel free to take it as a reference.

Refactor might happen inevitably. Hence, codes are organized in branches, so that no huge change would be needed to commit.

# Naive Implementation

I would finish this with minimal support, which means CPU+GPU+SSD structure without any further optimization. If I have enough reason/opportunity for continuous development, I might go on with this in another branch.
